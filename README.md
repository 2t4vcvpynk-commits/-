# 👊 KOBUSHI 3D

自分でキャラをカスタマイズして、フレンドとネット越しにルーム対戦で殴りあえるブラウザ3D格闘ゲーム。

- **キャラメイク**: 名前・髪型(6種)・顔・アクセ(6種)・体格・身長・6か所のカラー、性能が変わるスタイル(バランス / パワー / スピード)
- **オンラインルーム対戦**: 「ルームを作る」で4文字コード発行 → フレンドがコード入力 or 招待リンクで参加
- **コロシアムで3Dバトル**: 観客席に囲まれた円形闘技場を、背中越しの3人称カメラで自由に走り回って戦う。ロックオン切替、柱を盾に必殺技を防ぐ立ち回りも
- **格闘アクション**: 3段パンチコンボ、キック、ガード、無敵の回避ステップ、ジャンプ＆空中攻撃、ゲージ消費の必殺技「気功弾」、2本先取・60秒ラウンド
- **CPU練習モード**、スマホのタッチ操作対応、効果音つき（素材ファイル不要）

## 遊び方（ローカル）

```bash
npm install
npm start
# → http://localhost:3000
```

同じWi-Fiのフレンドなら `http://<あなたのPCのIP>:3000` で対戦できます。

## ネットでフレンドと遊ぶ（公開する）

WebSocket が使えるNodeホスティングならどこでも動きます。

- **Render（無料）**: このリポジトリをRenderの「New → Blueprint」で選ぶだけ（`render.yaml` 同梱）。
- **Railway / Fly.io など**: `Dockerfile` 同梱。`PORT` 環境変数に対応。
- **今すぐ試す**: ローカルで起動して `npx cloudflared tunnel --url http://localhost:3000` などのトンネルでURLを共有。

発行されたURLを開いて「ルームを作る」→ 表示されたリンクをフレンドに送れば対戦開始！

## 操作

| 操作 | キーボード / マウス | スマホ |
| --- | --- | --- |
| 移動（カメラから見た方向へ） | WASD / 矢印 | 左スティック |
| 視点 | マウス（画面クリックで固定・Escで解除） / Q・E | 画面ドラッグ |
| ロックオン切替 | Tab / F | ロック |
| パンチ（連打で3段コンボ） | 左クリック / J | パンチ |
| キック | 右クリック / K | キック |
| ガード（長押し・削りダメージのみ） | L / C | ガード |
| 回避ステップ（無敵） | Shift | 回避 |
| ジャンプ（空中でパンチ/キック） | Space | ジャンプ |
| 必殺技（SPゲージMAX時） | U / V | 必殺 |

攻撃を出すと、近くにいる相手（ロックオン中は常に相手）の方へ自動で振り向きます。
SPゲージは攻撃を当てる・受けると溜まります。

## 構成

```
server.js                 HTTP配信 + WebSocketルームサーバー
public/index.html         画面
public/js/main.js         メニュー・キャラメイク・画面遷移
public/js/game.js         ゲームループ、操作、当たり判定、相手の補間表示、カメラ
public/js/fighter.js      パーツから組み立てるファイターモデルとモーション
public/js/shared/room.js  ラウンド/HP/ダメージ判定（サーバーと練習モードで共通）
public/js/shared/profile.js キャラ設定の選択肢と検証
```

ネット同期は「各自が自分のキャラの位置を送信し、相手は100ms遅れで補間表示」「攻撃のヒットは攻撃側が判定し、HPとダメージはサーバーが距離チェックの上で確定」という方式です。
